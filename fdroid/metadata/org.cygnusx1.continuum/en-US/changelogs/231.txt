# Notes
`Reddit` broke some of the `API` related to loading more comments, but only for the `RedReader` client ID.

There is a new setting, `Settings > Interface > Comment > Use Old Load More Comments Method`. It does it the old way that works with non-`RedReader` client IDs. `RedReader` is the default client ID.
